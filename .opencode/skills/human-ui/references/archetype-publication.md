# Publication

## Structural contract

Own editorial hierarchy, reading measure, metadata, navigation between stories, and the relationship between lead and supporting content. Long-form favors continuity; news-dense favors scanning and recency.

## Required states

Support long titles, missing images, updated/corrected labels, author metadata, reading progress where useful, and mobile type measure. Preserve semantic heading order.

## Blend contract

Use `search-discovery` for archives and filters, `media-experience` for image-led stories, and `landing-story` for a branded homepage. `editorial-humanist` is common but not mandatory.

## Anti-patterns

Avoid treating every story as an identical card, using UI chrome that competes with reading, or forcing serif type, square corners, or monochrome palettes as universal editorial rules.
