# Immersive Cinematic

Let high-quality media establish place and emotion. Compose text, controls, and metadata as intentional layers around a focal scene. Use framing, crop, scale changes, and restrained depth to guide attention.

Motion may reveal perspective or continuity, but core actions must remain immediate. Provide robust contrast and media fallbacks.

Avoid full-bleed media without information hierarchy, unreadable overlays, perpetual parallax, generic luxury styling, and using cinematic pacing inside transactional steps.
