# Editorial Humanist

Treat typography and pacing as composition. Mix display, body, and metadata roles deliberately; a serif is optional. Use asymmetric balance only when it strengthens narrative or hierarchy. Let images carry context rather than decorate empty areas.

Favor readable measure, varied section cadence, captions, and meaningful transitions between dense and quiet regions. Motion should resemble page or scene continuity.

Avoid random misalignment, illegible expressive type, forced paper textures, decorative pull quotes, and treating every UI as a magazine.
